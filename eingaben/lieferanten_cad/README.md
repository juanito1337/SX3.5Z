# Lieferanten-CAD / bestätigte Zeichnungen

Hier erhaltene STEP-/NX-/Zeichnungsdateien ablegen, jeweils mit Hersteller, Artikel,
Revisionsstand, Quelle, Abruf-/Bestätigungsdatum und Lizenz-/Nutzungsbedingungen.
Keine Raumreferenz als Original-Hersteller-CAD ausgeben. Das Paket enthält derzeit keinen
neu bestätigten ATC-Spindelsatz. Nicht automatisch Dateien hochladen oder Angebote auslösen.
