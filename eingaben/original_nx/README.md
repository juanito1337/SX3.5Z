# Hier eine geschützte Kopie der echten NX-Ausgangsbaugruppe ablegen

Dieses Paket enthält keine auf deinem Rechner erzeugten `.prt`-Dateien.
Kopiere die vollständige Baugruppe einschließlich ALLER referenzierten Einzelteile hierher.
Nur eine Kopie verwenden. Diese Eingaben dürfen nicht überschrieben werden.
Dateinamen/Hashes/Revision zuerst inventarisieren; daraus getrennte Arbeitskopien und neue
CNC-Ausgaben erzeugen. Die bisherigen Standardparameter mit lokalen Änderungen vergleichen.
Dieser Ordner ist standardmäßig von Git ausgenommen; für einen Cloud-Lauf müssen benötigte
Dateien bewusst und unter Beachtung ihrer Vertraulichkeit bereitgestellt werden.
